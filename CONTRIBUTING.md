# Contributing

1. Clone the repository and install: see `web/README.md` (needs Node 20 or newer).
2. Create a branch: `git checkout -b my-change`.
3. Make the change in `web/`. Run `npm run check` from `web/` before you push (type check, lint, unit tests, build, browser tests).
4. Push the branch and open a pull request into `main`. The checks run automatically.
5. After a merge to `main`, the live site updates by itself.

Where things live is in `web/README.md` (folder map, how to add a demo trip, how to rename the product).
