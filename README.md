# Trip planner prototype

Collaborative group-trip planning, built from `docs/TRAVELY_PROTOTYPE_PROTOCOL.md`.

```
docs/    Product protocol (the spec this prototype follows)
web/     The prototype app. Start with web/README.md
.tools/  Portable Node.js used to build and run the app (not part of the product)
```

The product name is set in one file, `web/lib/brand.ts`, so switching between Travely and Joliday is a one-line change.
